# AI Analysis

Per-session analytics outputs for the petersoul.co.uk archive project. Each analysis follows the `ai-analysis` skill workflow, producing structured metrics on user behaviour, AI behaviour, and improvement opportunities from individual Kilo session transcripts.

## Contents

- Per-session analysis documents using the template at `_docs/ai-dev-guides/ai-stats-template.md`
- Improvement recommendations exported to `ai-outcomes/`

## Workflow

1. Read session transcript from `.ai-activity/ai-sessions/kilo-code/`
2. Apply analysis framework from `_docs/ai-dev-guides/ai-stats-template.md`
3. Record findings here and recommendations in `ai-user-outcomes/`

See `.skills/ai-analysis/skill.md` for the full analysis workflow.
