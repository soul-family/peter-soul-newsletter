# AI Reports

Analytics and statistics reports for AI development activity across the project. These reports aggregate session data from all AI co-developers.

## Contents

- `ai-development-statistics.md` — Human-readable stakeholder report
- `project-stats-totals.md` — Internal analysis with full session breakdown
- `project-stats-totals.json` — Raw aggregate data

## Workflow

1. Read session data from `.ai-activity/ai-sessions/`
2. Apply analysis framework from `_docs/dev-guides/ai-dev-guides/ai-stats-template.md`
3. Record findings here and recommendations in `.ai-activity/ai-user-outcomes/`

See `.skills/ai-analysis/skill.md` for the full analysis workflow.
