# Archive Guide

## Overview

Family tree content is organized in individual folders under `content/familytrees/`. Each family tree has its own `index.html`, and a shared `credits.html` provides attribution.

## Structure

```
content/familytrees/
├── index.html          # Main family tree index
├── credits.html        # Attribution and credits
├── bailey/index.html
├── holt/index.html
├── soul/index.html
└── ...                 # One folder per family tree
```

## Navigation

- The main `index.html` lists all family trees with internal links.
- Each family tree page links back to the index.
- A `Credits` link at the bottom of each tree points to `credits.html`.

## Future Migration

Family tree content is migrated to a dedicated repository. Tasks for this migration are tracked in `.todo/todo-familytrees.md`.

## Contact & Privacy

All plaintext email addresses remove from the family tree HTML pages to prevent harvesting by bots. For enquiries about the family tree archive, use updated contact address (obfuscated to protect against automated scraping).

Privacy of living individuals strictly protect. Details of living family members store in a separate private document and only release to verified family members or on serious research requests.
