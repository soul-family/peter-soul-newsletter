## v1 vs v2: Authoring and Maintenance Approach

| Aspect | v1 (Original 2002–2019) | v2 (Updated 2026+) |
|--------|--------------------------|---------------------|
| **Authoring format** | HTML generated by NetObjects Fusion 7 WYSIWYG editor | Markdown text source with static site generation |
| **Editing workflow** | Visual drag-and-drop in NetObjects Fusion | Plain-text Markdown files in any editor |
| **Version control** | No built-in versioning; files published as-is | Git-based with full history, branches, and commits |
| **Content structure** | Table-based HTML layouts from WYSIWYG | Semantic Markdown converted to HTML at build time |
| **Maintenance** | Requires original NetObjects Fusion software | Any Markdown-compatible toolchain |
| **Portability** | Tied to NetObjects Fusion project files | Fully portable text files |
| **Automation** | Manual publishing process | Automated builds, deployments, and checks |
| **Collaboration** | Single author in proprietary editor | Multiple contributors via Git and Markdown |

### Advantages and Disadvantages

**v1 — NetObjects Fusion 7 / WYSIWYG HTML**
- Advantage: What you see is what you get — visual editing matches rendered output
- Advantage: No technical knowledge required to update content
- Advantage: Built-in site management and publishing workflow
- Disadvantage: Requires proprietary software to edit original files
- Disadvantage: Generates verbose, table-based HTML that is hard to maintain manually
- Disadvantage: Poor version control integration; no built-in collaboration
- Disadvantage: Project files are not portable across tools or platforms

**v2 — Markdown / Static Site Generation**
- Advantage: Plain-text source is version-control friendly and collaborative
- Advantage: Lightweight editing in any text editor or Markdown tool
- Advantage: Automated builds, testing, and deployment pipelines
- Advantage: Semantic output is cleaner and more accessible
- Disadvantage: Requires build step and toolchain knowledge
- Disadvantage: Visual editing requires separate preview or static site generator
- Disadvantage: Migration from existing HTML requires conversion effort
- Disadvantage: Some original design fidelity may be lost without careful template work
