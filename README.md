# Peter Soul Newsletter

This repository preserves the newsletter columns written by Peter Soul for the Thames Valley Group of Advanced Motorists newsletter, published between July 2002 and March 2019. The columns, titled "A Physicist Writes...". The attribution, source notes, images, and maintenance documentation are kept here as a focused archive.
