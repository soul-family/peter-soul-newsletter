# Browsing the Newsletter

## Navigation

- **Blog posts** — open `content/columns/` to browse posts by date
- **Links** — open `content/columns/index.html`

## Understanding Dates

Each page includes a `Latest Updated on` annotation at the bottom. This shows when the content was last revised in the archive.

## Images

Click any image to view it at full size. Some family tree pages include thumbnail images that link to larger versions.

## External Links

Links to external websites open in a new tab or window. The archive does not maintain or control external content.

## Browser Compatibility

The archive works best in modern browsers: Chrome, Firefox, Safari, or Edge. JavaScript is not required for basic navigation.
