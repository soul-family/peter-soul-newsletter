# Archive.org Searching

## Overview

This guide explains how to find and browse the petersoul.co.uk archive on Archive.org (Internet Archive) using the Wayback Machine.

## Wayback Machine URL

The main Wayback Machine entry point for the archive is:

```
https://web.archive.org/web/*/https://petersoul.co.uk
```

This shows all captured snapshots of the original website over time.

## Browsing by Date

1. Visit the Wayback Machine URL above
2. A calendar view shows available capture dates
3. Click any year, then month, then day to navigate
4. Select a specific timestamp to view that version of the site

## Finding Specific Content

### Blog Posts

Blog posts are organized by month and year. To find a specific post:

1. Use the Wayback Machine URL with a specific date if known
2. Or browse the archive's internal navigation once loaded

### Family Trees

Family tree content is preserved separately. See the `_docs/family-tree/archive-guide.md` more information.

## Offline Access

To download the entire archive for offline use:

1. Visit the Archive.org item page
2. Click **Download Options**
3. Choose the desired format (ZIP, TAR, etc.)
4. Extract and open `index.html` in a browser

## Search Within the Archive

Archive.org provides full-text search for many items. To search within this archive:

1. Go to the item page on Archive.org
2. Use the search box to find specific words or phrases
3. Results link directly to the relevant pages

## Mirror and Backup

The archive on Archive.org serves as a public mirror. For personal backups, use the download options or clone the GitHub repository.

## Contact

If you cannot find specific content or encounter issues with the Archive.org version, please contact the archive maintainers through the repository.
