# Storage Manage Invite

## Overview

This guide explains how invited users can access the archive on GitHub.

## Getting Started

### Accepting the Invitation

1. Check your email for the GitHub invitation
2. Click the invitation link
3. Log in to GitHub or create an account
4. Accept the invitation

### Accessing the Repository

1. Go to [github.com](https://github.com) and log in
2. Navigate to the repository URL provided in your invitation
3. You should now see the repository in your dashboard

## Viewing Statistics

### Repository Statistics

GitHub provides several built-in statistics:

#### Traffic Statistics

1. Go to the repository on GitHub
2. Click **Insights** > **Traffic**
3. View:
   - Total views and unique visitors
   - Popular pages and content
   - Referring sites
   - Geographic distribution of visitors

#### Code Frequency

1. Click **Insights** > **Code frequency**
2. View additions and deletions over time
3. See commit activity patterns

#### Contributors

1. Click **Insights** > **Contributors**
2. View all contributors and their commit counts
3. See contribution frequency

#### Commit Activity

1. Click **Insights** > **Commit activity**
2. View commits per day/week
3. Identify peak activity periods


## Browsing the Archive

### Viewing Content

As a viewer, you can:

- Read all files directly on GitHub
- Click any file to view its contents
- Navigate using the file tree on the left

### Downloading the Archive

1. Click the green **Code** button
2. Select **Download ZIP**
3. Extract the ZIP file
4. Open `src-content/` folder in a web browser to browse offline

### Searching the Archive

Use GitHub's search feature:

1. Press `t` to focus the file finder
2. Type a filename or path
3. Navigate to the file

Or use the repository search bar:

1. Type keywords in the search box at the top
2. Results show matching files and code

## Understanding the Structure

### Key Directories

- `src-content/` - Content for the public website
- `src-content/assets/` - Images, CSS, and other assets
 - See git commit history for original site files and preparation folders (v1 migration artifacts excluded)

## Viewing History

### Commit History

1. Click **Code** tab
2. Browse the commit history at the top
3. Each commit shows:
   - Date and time
   - Author
   - Commit message
   - Files changed

### File History

1. Open any file
2. Click **History** to see all changes to that file
3. Compare different versions side by side

## Getting Help

If you encounter issues:

- Check the repository **Issues** tab for known problems
- Contact the repository owner or maintainers
- Refer to the documentation in `_docs/`

## Your Role

As an invited user, you can:

- View and read all content
- Download the archive for personal use
- Suggest improvements via issues
- Report errors or broken links

If you need write access to contribute changes, contact the repository owner.
