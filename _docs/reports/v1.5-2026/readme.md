# Newsletter Archive - v1.5 (2026)

## About This Report

This report documents the first major update to the newsletter archive since the original backup. Version 1.5 modernises the markup with HTML5 doctype, CSS3 variables, and UTF-8 encoding while preserving every column article, diagram, and source note exactly as written.

## What Changed

### Technical Updates

- **HTML5 doctype and modern markup standards** - Updated for long-term compatibility
- **Universal encoding** - UTF-8 applied to all content pages
- **CSS3 variables** - Consistent styling across pages
- **Page-type templates** - Separate templates for static pages and blog posts
- **Mobile browsing** - View the complete archive on any device
- **Relative links** - All navigation works without internet connection
- **Update dates visible** - Each page shows when it was last revised

### Content Improvements

- **Column post titles added** - Each page includes the column title
- **Column URL consistency**
- **Sticky sidebar navigation and footer positioning** - Improved readability
- **Asset deduplication** - Applied across commits

### What Changed

- External search forms excluded (relied on third-party services)
- Empty "notes" pages with no content
- Outdated contact information
- Proprietary formatting that restricted editing

### What Stayed the Same

- **Every word preserved** - Column articles, notes, and commentary unchanged
- **Original diagrams intact** - ASCII family tree charts with original spacing
- **All sources kept** - Manuscript references, bibliography, external links
- **Author's voice** - Grammar, phrasing, and style exactly as written
- **Historical dates** - Original publication dates preserved where available

## Why This Update Matters

The original website was built with tools that are no longer available (NetObjects Fusion) and formats that are difficult to maintain. This edition moves the archive to an open, standard format that:

- Can be edited with any text editor
- Tracks every change with full history
- Allows multiple contributors
- Works reliably on modern and future devices
- Can be hosted anywhere (GitHub Pages, personal server, local computer)


## For Contributors

If you're helping maintain the archive:

- All content in plain text files
- Standard folder structure
- Clear contribution guidelines
- Automated checks for common issues
- Full change history for accountability
